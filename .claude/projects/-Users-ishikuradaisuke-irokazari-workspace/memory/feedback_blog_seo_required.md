ブログ記事ドラフトを作るたびに以下の3点を必ず記載する。1つでも抜けたら未完成。

## 必須3点セット

**① SEOタイトル（検索表示用）**
- 本文タイトルとは別に設定する
- 検索キーワードを含める（天然石名・作業名・ブランド名など）
- 32文字前後が目安

**② パーマリンク**
- 英数字・ハイフン区切り
- 記事内容を端的に表す
- 例：`/hiroshima-mineral-marche-tenseki-2026-03`

**③ メタディスクリプション**
- 120〜160文字
- 記事の要約＋キーワード含む
- 読者がクリックしたくなる文にする

**Why:** 過去に複数回指摘されている。思考ログにも「パーマリンク・メタディスクリプションの漏れを即座に指摘」と記録されているにもかかわらず繰り返し抜かしている重大な違反。

**How to apply:** ブログドラフトのNotionページを作る際、「記事情報」セクションの直後に「SEO設定」セクションを必ず入れる。本文より先に書く。
