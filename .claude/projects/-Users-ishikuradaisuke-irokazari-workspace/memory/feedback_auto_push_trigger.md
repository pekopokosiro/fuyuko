---
name: auto_push_trigger
description: セッション終了フレーズ（お疲れ様・おやすみ・いってらっしゃい）でgit pushを自動実行する
type: feedback
---

セッション終了を示すフレーズが出た時点で、許可確認なしに即 `git push origin main` を実行する。

対象フレーズ：「お疲れ様でした」「おやすみなさい」「いってらっしゃい」

**Why:** これらのフレーズはセッション終了のサインであり、pushはセットで行うもの。毎回許可を取るのは手間。ユーザーが明示的にルール化した。

**How to apply:** 自分がこれらのフレーズを言う場面（応答の締め・見送り）でも、ユーザーが言った場合でも、即座に `git push origin main` を実行する。コミットが必要な未コミット変更があれば先にコミットしてからpushする。
