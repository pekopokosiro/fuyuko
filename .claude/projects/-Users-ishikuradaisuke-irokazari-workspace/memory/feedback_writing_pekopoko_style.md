## 何が悪かったか

### ① 石の説明を「一般的な定義」で書いた
- AI：「浄化の定番石。どんな石とも相性が良く、組み合わせに重宝します。」
- pekopoko：「いつも仕入れている水晶とは一味違います！水晶内部に閉じ込められた謎の鉱物。inクォーツ系の水晶となっています。珍しいものを手に入れることができました。」

→ 正解は「今回仕入れた個体の特徴・実際の状態」を書くこと。一般論ではなく目の前の石を描写する。

### ② 素材の状態を書かずに効能だけ書いた
- AI：「金運・決断力を高めると言われています。ゴールドのワイヤーラップ仕上げでそのまま使えるタイプ。」
- pekopoko：「ゴールドのワイヤーラップ仕上げでそのまま使える状態で販売されていました。」

→ 仕入れ記事では「どういう状態で手に入れたか」が読者に有益な情報。効能だけ書いても仕入れレポートにならない。

### ③ 繋ぎ文・導入を入れなかった
- pekopoko が追加：「それでは戦利品をご紹介していきます。」「基本的に仕入れた天然石はマクラメ編みや、レザークラフトの素材として使用する予定です。」

→ 石の羅列に入る前に一言説明を入れることで読者が読みやすくなる。

### ④ 「（括弧で補足）」を多用した
- AI：「フローライト（ペントップ）」
- pekopoko：「フローライト」のみ

→ 括弧での補足は読みにくくなる。必要なら本文に組み込む。

## 今後の原則

- 仕入れ・制作レポートは「一般知識」ではなく「実際に見た・触れた・購入したもの」を書く
- 効能の定型文より「今回手に入れたものの特徴・状態・用途予定」を優先する
- 繋ぎ・導入文は必ず入れる
- 括弧補足は最小限にする

**Why:** AIが「知っている定義」を並べるのではなく、pekopokoが「実際に経験したこと」を語る文章にする必要がある。読者が求めているのは図鑑ではなく、作家の目線からのリアルな情報。
