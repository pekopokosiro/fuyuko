description: ドラフトが「公開済み」かどうかは会話ログ・Notionだけで判断せず、必ずNote/ブログ/Instagramを実際にブラウジングして確認する
type: feedback

Notionにドラフトページが残っていても、すでに公開済みである場合が多い。
会話ログや引継ぎメモの「ドラフト」表記をそのまま信用してブリーフィングに出してはいけない。

**Why:** 公開済みのNoteやリールをドラフト扱いで何度も案内され、同じことを繰り返し言わせてしまった。

**How to apply:**
- ブリーフィング時はNote（note.com/pekopoko3022）・公式ブログ（irokazari.com）・Instagramを実際にWebFetchして公開済み記事を確認する
- Notionのドラフトページのステータスフィールドも確認する
- 「公開済み」と確認できたものは「投稿待ち」欄から除外する
- 判断できない場合は「確認できませんでした」と正直に伝える
