## 【最上位ルール】憶測による表現の完全禁止

確認できていない情報を事実のように書くことは詐欺行為。産地・効能・数値・仕様・出所不明の情報すべてに適用。

- 知らないことは書かない。空欄のまま渡す
- 「〜と思われます」「〜のはずです」を事実として提示しない
- 雰囲気を盛り上げるために情報を補完・創作しない
- pekopoko未確認の情報を一切記載しない

**Why:** pekopoko直接指示。盛り上げのための嘘は詐欺行為であり、ブランドの根幹を損なう。

## ブログドラフト チェックリスト

- SEOタイトル記載あり
- パーマリンク記載あり
- メタディスクリプション（120〜160字）記載あり
- 禁止語（パワーストーン・エネルギー・波動）ゼロ
- 断言表現（〜してくれます・〜の石です 等）ゼロ → 「〜と言われています」止まり
- 語尾：です・ます調で統一
- 私的・感情的・文学的冒頭フックなし

## SNS投稿文 チェックリスト

- Instagram：ハッシュタグ3〜5個以内
- X：ハッシュタグ1〜2個・文字数を明示して140字以内を確認
- 語尾：です・ます調で統一
- 禁止語ゼロ
- 私的・感情的表現なし

## 差し戻し基準

上記のいずれか1つでも満たしていない場合、クロウが該当STEPに差し戻す。承認なしに最終稿としない。

**Why:** 本日（2026-03-22）に同一会話内で6件の違反が発生。ハッシュタグ数・禁止語・断言表現・SEO3点セット未記載・私的表現・敬語未徹底。思考ログ記載済みのルールも含まれており、参照しても適用できていなかった構造的問題。チェックリストを明文化することで属人的な見落としを防ぐ。

**How to apply:** コンテンツ生成のSTEP3（クロウ最終承認）で本リストを全項目照合する。
