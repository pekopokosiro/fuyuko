## 実施タイミング
- **月1回**（毎月末の週末前後）
- 週末が近づいたら（金曜あたり）pekopoko に「今月のChrome分析やりますか？」とリマインドして、以下のプロンプトを提示する

## Claude in Chrome 用プロンプト（毎回このまま渡す）

```
Instagramの管理画面（プロフェッショナルダッシュボード）を開いて、以下のデータをすべて収集してください。

【収集項目】
1. アカウント基本情報
   - フォロワー数
   - フォロワーの曜日別アクティブ時間帯（何曜日に何人）

2. 期間別パフォーマンス（過去7日・14日・30日）
   - 総ビュー数
   - リーチしたアカウント数
   - インタラクション数
   - フォロワー比率 vs フォロワー以外比率（ビュー）
   - プロフィールアクティビティ数
   - 外部リンクタップ数

3. コンテンツタイプ別パフォーマンス（30日）
   - リール動画・ストーリーズ・投稿（フィード）それぞれのビュー比率・インタラクション比率

4. 直近14日間の投稿別データ（リール・フィード・カルーセル）
   - 投稿内容・日付・ビュー・リーチ・インタラクション・いいね・コメント・保存

5. ストーリーズ（直近14日）
   - 投稿内容・日付・ビュー・リーチ・インタラクション

6. 過去30日間トップコンテンツ（ビュー順TOP8）
   - 投稿内容・日付・ビュー・リーチ・いいね・コメント・保存

収集が終わったら、表形式でまとめて出力してください。
```

## report.pyとの役割分担
- **report.py**：投稿別データ（リーチ・いいね・保存・再生数）の自動蓄積。毎回実行。
- **Claude in Chrome**：ストーリーズ・アカウント全体傾向・曜日別アクティブ・非フォロワー比率の月次補完。月1回手動実行。
