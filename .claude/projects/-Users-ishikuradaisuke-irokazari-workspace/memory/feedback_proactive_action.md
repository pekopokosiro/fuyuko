会議・ブリーフィング・データ確認などの流れで発生する定型作業は、言われなくても自分で判断して実行する。

**Why:** 毎回「report.pyを回して」「メモリ更新して」「gitにpushして」と指示するのはオーナーの作業負荷を増やす。AIが代行できることは代行するのが基本方針（CLAUDE.md §6）。

**How to apply:**
- 会議後 → Notionに計画メモを更新、メモリを更新、git push
- **report.py・ga4_report.pyは週末の振り返り＆来週計画立案セッションで実行する**（朝のブリーフィングではない）。データを元に翌週の作戦を組み直すのがこのセッションの目的。実行順：report.py → ga4_report.py → データ分析 → Notion週次計画更新
- 新しい方針・フィードバックが出た → その場でメモリに記録してMEMORY.mdを更新
- 報告は「やりました」ではなく「やった内容と結果」を簡潔に
