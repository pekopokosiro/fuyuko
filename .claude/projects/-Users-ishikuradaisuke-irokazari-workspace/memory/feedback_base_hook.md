---
name: BASEリライト 冒頭3行フックルール
description: EC商品説明文の冒頭3行は「この石を手に取った体験・選んだ理由」から入る。汎用的なマーケティング文句は禁止。
type: feedback
---

冒頭3行は「この石・この作品と出会った瞬間の体験」から始める。

**Why:** 既存のBASE商品説明（ルチルクォーツ・フローライト等）はすべてこの形式で書かれている。「色が変わります」「手に取りたくなる」などの汎用フックはpekopoko の文体と全く合わない。

**How to apply:**
- 1行目：この石を手に取った時の具体的な観察・体験（例：「光に当てて角度を変えるたびに、石の色が変わりました。」）
- 2行目：その続き・詳細（どう変わったか、何を感じたか）
- 3行目：現象・特徴の名称や背景説明

**NG例：**
- 「見るたびに、色が変わります。」→ 汎用すぎる
- 「手に取りたくなる石です。」→ 主観的すぎる・押しつけ

**OK例（ルチルクォーツ実績）：**
「天然石を選ぶとき、手に取らないとわからないことがあります。
こちらは広島のマルシェで、数あるルチルの中からこの一粒を選び抜いてきました。
針の入り方や水晶の透明具合を、元天然石ショップ店長の目線で厳選しております。」
