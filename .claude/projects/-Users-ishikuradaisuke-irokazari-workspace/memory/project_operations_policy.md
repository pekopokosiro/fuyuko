## コンテンツ制作フロー（確定）

**撮影 → 記事化 → 出品リール** の流れで動かす。
- 仕入れ石・新作品の撮影完了 → ブログ記事・NOTE記事のドラフトをClaude Codeが生成
- 出品時 → 制作動画＋出品リールをセットで投稿

**Why:** 素材（写真・動画）を撮ったら複数媒体に展開することで作業効率を最大化する。

**How to apply:** pekopoko から撮影データを受け取ったら即座に記事ドラフト・キャプション・ハッシュタグを生成して渡す。

## おこげ・もなか投稿スタイル（確定）

- **スタイル：** チャイハネ「おかか」に寄せた1枚完結型
- **頻度：** 3日おきに投稿
- **準備：** 画像生成を3枚分まとめて行い、投稿文もセットで用意する
- 必ず `#おこげともなか` を入れる（広報インスタのルール）

**Why:** 1枚完結スタイルは継続しやすく、キャラクターの日常シーンで世界観を伝えられる。
