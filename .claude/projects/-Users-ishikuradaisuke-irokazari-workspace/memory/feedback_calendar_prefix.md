---

新規カレンダーイベントを作成する際は、タイトルの先頭にカテゴリプレフィックスをつける。

**Why:** 複数プロジェクト（副業・本業）でGoogleカレンダーを共用しているため、一覧で見たときに判別しやすくする。

**How to apply:**
- irokazari+関連（出品・投稿・制作・イベント等）→ 【副業】
- 本業（デザイン広報職）関連 → 【本業】
- 既存イベントは変更しない。今後新規作成分から適用する。
