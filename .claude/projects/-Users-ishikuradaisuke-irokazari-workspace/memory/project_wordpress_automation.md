WordPress REST APIを使い、Claudeが公式ブログ（irokazari.com）を自動投稿する仕組みを構築する。

**Why:** pekopoko自身が投稿操作をしなくてもブログ発信が回るようにする。新作・イベント出店などのトリガーがあれば自動で記事化・公開まで完結させたい。

**How to apply:** 新作出品・イベント参加など変化があれば自動で記事を下書き作成→「確認をお願いします」と伝える→OKが出たら公開。問題なさそうなら完全自動化へ移行。

## ステータス（2026-04-10）

**稼働中** ✅

- WordPress REST API接続済み（.envに認証情報保存）
- 記事作成・画像アップロード・アイキャッチ設定・公開まで全自動化済み

## 記事構成ルール

```
① 楽天アフィリエイトコード（冒頭）
② 記事本文（こんにちは〜 で始まる）
③ フッター固定ブロック（バーチャルショップ・BASE・Instagram・X リンク）
④ 楽天アフィリエイトコード（末尾）
```

- テンプレート（フッター本体のみ）: `指示書/wp_footer_only.html`
- 楽天コードHTMLは記事生成スクリプト内に記載

## アイキャッチ生成ルール（Pillow）

- サイズ：1280×640px
- 分割：黄金比（左38%テキスト / 右62%商品写真）
- 左エリア：タグ・メインタイトル・サブコピー（ベネフィット訴求）・ブランド名
- タグ背景はテキスト幅を動的計算してぴったり合わせる
- サブコピーは「誰に？どんな時に？」のベネフィット軸で書く
- 生成スクリプト参照で再現可能

## 画像管理ルール

```
images/blog/
├── 商品写真/
│   └── [商品名]/   ← 商品ごとにフォルダ
│       ├── 商品名_01.jpg 〜 _07.jpg
│       └── 商品名_eyecatch.jpg
├── イベント/
├── おこげともなか/
└── 汎用・背景/
```

- ファイル名：`商品名（ハイフン区切り）_連番.jpg`
- アイキャッチは `_eyecatch.jpg` で統一

## トリガー別フロー

| トリガー | 記事タイトル例 | 本文の軸 |
|---|---|---|
| 新作出品 | 〇〇を出品しました | 石の意味・ベネフィット・仕様 |
| イベント参加 | 〇〇に出展します | イベント詳細・見どころ |
| 制作レポート | 〇〇を作りました | 制作の背景・こだわり |

## 確認フロー（現在）

1. Claude：記事を自動作成（下書き）
2. Claude：「確認をお願いします」と声をかける
3. pekopoko：管理画面でチェック
4. pekopoko：「OK」で公開 or Claude経由で公開
→ 問題なさそうなら段階的に完全自動化へ
