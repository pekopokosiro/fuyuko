---
name: 私的・感情的表現の禁止
description: キャプション・ブログ・商品説明文で私的・感情的な表現を使わない
type: feedback
---

私的な表現・感情的な語り口は使わない。「虫唾が走る」レベルで嫌い。

**Why:** pekopoko は構造思考型で、個人の感情を前面に出す文章を好まない。「大切な人へ、言葉の代わりに石を選んだ」のような文学的・私的表現は本人の声と一致しない。

**How to apply:** キャプション・ブログ・商品説明文すべてで適用。体験談を書く場合も「何があったか・何を選んだか・なぜか」を事実ベースで書く。感情を匂わせるにしても「〜と思いました」止まりにする。詩的・文学的な冒頭フックは禁止。
