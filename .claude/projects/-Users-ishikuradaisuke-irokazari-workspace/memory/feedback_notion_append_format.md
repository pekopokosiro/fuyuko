---
name: Notion追記のフォーマットルール
description: Notionの時系列ページに追記する際は日付順を守る
type: feedback
---

時系列で記録されているNotionページ（トレーニング記録・日記など）に追記する際は、必ず**既存の日付順の末尾に追加**する。

**Why:** 3/24の後に3/25の記録を追加すべきところを、セクションの途中に差し込んでしまい修正が必要になった。

**How to apply:**
- 追記前に既存ページの構造（日付の並び順）を確認する
- 最新日付のエントリーの「後」に追加する
- セクション見出しの形式（「### 2026/3/25」など）も既存フォーマットに合わせる
